# 后端编码约定

- API 层验证输入、鉴权并转换响应；业务规则进入 service，数据访问进入 repository，模型调用进入 ai。
- 权限校验在服务端执行，访问记录必须校验归属；不得信任客户端传入的用户标识或模型声称的权限。
- 数据访问使用参数化查询；事务覆盖需要原子完成的写操作。数据库变更交由 db/ 管理。
- 外部请求设定超时；重试有次数上限，仅重试安全或幂等操作。日志包含关联标识，避免密钥和完整敏感内容。
- 请求与响应契约保持明确，错误返回稳定错误码和可理解的信息，不暴露内部堆栈。
- 配置从服务端环境读取；配置缺失明确报错，不虚构成功或偷偷使用生产凭证。
- 使用 Node.js 24 + TypeScript ESM；当前 HTTP 入口使用 node:http，业务复杂后再评估框架。运行 npm run check 验证。
- 业务测试覆盖权限、输入边界、主要失败路径和事务行为；外部模型的单元测试使用可控替身，真实调用归 eval。
